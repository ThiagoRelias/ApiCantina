# ApiCantina

Projeto desenvolvido para a atividade de criação de API para uma Cantina.

A Api permite realizar o cadastro, consulta e remoção de lanches.

#Tecnologias utilizadas

-Java 21
-Spring boot
-Mysql
-maven

#Estrutura do projeto

o projeto está dividido em :
-model - contém as entidades do sistema
-repository - contém os repositories responsáveis pelo acesso ao banco 
-controller - cóntém os endpoints da API 
-exception
-dto
-service
